Amazon Fresh Analytics - SQL Project

Tables used :
  Customers, Products, Suppliers, Orders, Order_details, Reviews

What I did :
  1.Created ER Diagram with Primary Key & Foreign Key relations
  2.Created tables using DDL with contraints like NOT NULL, UNIQUE, CHECK(Age>18), CHECK(Rating 1-5),DEFAULT PrimeMember="No"
  3.Did INSERT, UPDATE, DELETE, using DML
  4.Used WHERE, GROUP BY, HAVING, ORDER BY and JOINs
  5.Found High-Value Customers who spent >5000
  6.Calculated total revenue per order using Orders+Order_details Join
  7.Normalized Products table 
  8.Used Subqueries to find Top 3 products by revenue and customers with no orders

Business Insights :
   Top customers, Top Products, Revenue trends, Supplier performance and Customer satisfaction from Reviews
